# Security Policy

## Reporting a vulnerability

Please do not open a public issue for suspected security vulnerabilities.

Instead, report the issue privately through the GitHub security advisory workflow if enabled for the repository. If that is not available yet, contact the maintainer through the repository profile and include:

- a short description of the issue
- affected hardware / firmware revision
- reproduction steps
- potential impact

## Scope

This project is an embedded firmware project for ESP32-S3 hardware. Relevant reports may include:

- unintended exposure of credentials or secrets
- insecure update or flashing workflows
- unsafe network features if added in future
- vulnerabilities introduced by bundled third-party code

## Disclosure

Please allow reasonable time for investigation and remediation before public disclosure.
